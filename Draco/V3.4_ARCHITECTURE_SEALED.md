**PDB-to-269D Mapping:**
```
PDB (Cartesian) → Backbone Atoms (N, Cα, C, O)
                 → Dihedral Extraction (φ_i, ψ_i for i=1..90)
```

**Error Handling:**

- Non-standard amino acids: Log warning, skip dihedral if atoms missing
- Disorder regions: Mark in source_flags, non-fatal skip

### Pillar 4: V3.4_MOLECULAR_HANDSHAKE.md ✅ LOCKED

**FFI Architecture Decision: PRE-PARSED TORSION ARRAYS**

**Rationale:**
- **Architectural Continuity**: V3.3 Phase I.0.5 pattern—supervisor validates contracts, user ensures quality
- **Cycle Budget Sovereignty**: 750k cycles reserved for L5, not consumed by PDB parsing
- **ASIL D Determinism**: No platform-dependent string parsing, no format-variant branching
- **Research Reproducibility**: PDB parser published separately; supervisor independently auditable

**TorsionArray Struct Contract:**
```c
struct TorsionArray {
    float angles[180];              // φ/ψ pairs
    uint8_t sequence_length;        // ≤ 90
    uint8_t source_flags;           // from_pdb, has_disorder
    uint8_t pdb_id[4];             // PDB code
    uint64_t timestamp_us;         // Parser timestamp
    uint32_t crc32;                // Checksum
};
```

**Supervisor Validation:**
- Bounds check: sequence_length ≤ 90 (non-fatal warn if violated)
- Range check: angles ∈ [-π, π] (normalized dihedrals)
- Integrity check: CRC32 (informational, non-fatal mismatch)
- Mapping: Z_t[0:180] ← torsion_array.angles[0:2*sequence_length]

**User-Layer PDB Parser Responsibility:**
- Offline computation (Python BioPython, C MMDB, Rust pdbtbx)
- Cost: ~10ms Python, ~2ms C (no frame constraint)
- Output: TorsionArray, CRC32, timestamp
- Input to supervisor: `inject_torsion_array(state, torsion_array)`

**FFI Bindings Available:**
- C: Direct struct + FFI function
- Python: ctypes wrapper + BioPython integration
- Swift: Swift bridge (future mobile support)
