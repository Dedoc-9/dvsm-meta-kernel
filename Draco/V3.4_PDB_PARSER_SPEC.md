# V3.4 PDB Parser Specification
**Date:** 2026-05-21  
**Phase:** External modularity — user-layer PDB extraction  
**Status:** LOCKED (Design specification for offline parsing)

---

## Objective

Specify PDB file parsing protocol for extracting protein backbone dihedral angles (φ/ψ torsion angles). Parser executes in user layer (Python, C, Rust) with **unbounded cycle budget**—supervisor cycle budget untouched. Supervisor accepts only pre-validated TorsionArray output from this parser.

---

## Design Principle: Separation of Concerns

**Parser Responsibility (User Layer):**
- Read PDB files (raw Cartesian coordinates)
- Extract backbone atoms (N, Cα, C, O)
- Compute φ/ψ dihedral angles
- Normalize to [-π, π]
- Build TorsionArray struct
- Compute CRC32 checksum

**Supervisor Responsibility (Deterministic Core):**
- Validate TorsionArray bounds (sequence_length ≤ 90)
- Verify CRC32 (informational)
- Map angles to Z_t[0:180]
- Inject into L5 spectral resonance

**Result:** Parser complexity isolated from deterministic supervisor. ASIL D maintained.

## PDB File Format Overview

### ATOM Record Structure (Fixed-Width)

**PDB ATOM line format (v3.30 standard):**

```
Columns  Data Type    Field          Example
────────────────────────────────────────────────
1-6      Record name  "ATOM  "       ATOM  
7-11     Integer      Atom serial #  1
13-16    Atom name    Atom name      CA
17       Character    Alt. location  (space)
18-20    Residue name Residue code   ALA
22       Character    Chain ID       A
23-26    Integer      Residue seq.   1
27       Character    Code for ins.  (space)
31-38    Real(8.3)    X coordinate   -8.901
39-46    Real(8.3)    Y coordinate   4.127
47-54    Real(8.3)    Z coordinate   -0.555
55-60    Real(6.2)    Occupancy      1.00
61-66    Real(6.2)    Temperature    20.00
73-76    Integer      Element symbol (space)
77-78    Integer      Charge         (space)
```

**Example ATOM record:**
```
ATOM      1  N   ALA A   1      -8.901   4.127  -0.555  1.00 20.00           N
ATOM      2  CA  ALA A   1      -8.608   3.135  -1.173  1.00 20.00           C
ATOM      3  C   ALA A   1      -7.117   2.923  -1.301  1.00 20.00           C
ATOM      4  O   ALA A   1      -6.634   1.849  -0.921  1.00 20.00           O
ATOM      5  CB  ALA A   1      -9.437   1.881  -0.799  1.00 20.00           C
```

**Parsing Strategy:**
- Fixed-width fields (no CSV parsing, deterministic string positions)
- Extract X, Y, Z coordinates (float, columns 31-54)
- Extract residue number (integer, columns 23-26)
- Extract atom name (string, columns 13-16: "N", "CA", "C", "O")
- Chain filter: Accept chain A, reject others (chain ID column 22)

## Backbone Atom Extraction Algorithm

### Step 1: Read PDB File and Filter

**Pseudocode:**

```python
def read_pdb_backbone(pdb_file, chain_id='A', max_residues=90):
    """
    Read PDB file and extract backbone atoms (N, Cα, C, O).
    
    Args:
        pdb_file: Path to PDB file (plain text, PDB v3.30)
        chain_id: Chain identifier to extract (default 'A')
        max_residues: Maximum residues to include (hard truncate at 90)
    
    Returns:
        backbone_atoms: Dict mapping residue_id → {N, CA, C, O coordinates}
    """
    backbone_atoms = {}
    residue_buffer = {}
    
    with open(pdb_file, 'r') as f:
        for line in f:
            # Check record type
            if not line.startswith('ATOM'):
                continue
            
            # Extract fixed-width fields
            try:
                atom_serial = int(line[6:11])
                atom_name = line[12:16].strip()        # N, CA, C, O, etc.
                alt_loc = line[16]                      # Alternate location
                residue_name = line[17:20].strip()      # ALA, GLY, etc.
                chain = line[21]                        # Chain ID
                residue_id = int(line[22:26])           # Sequence number
                x = float(line[30:38])
                y = float(line[38:46])
                z = float(line[46:54])
            except (ValueError, IndexError):
                continue  # Malformed line, skip
            
            # Filter: Chain A only
            if chain != chain_id:
                continue
            
            # Filter: Hard truncate at 90 residues
            if residue_id > 90:
                continue
            
            # Filter: Skip alternate locations (take primary only)
            if alt_loc != ' ' and alt_loc != 'A':
                continue
            
            # Filter: Backbone atoms only (N, CA, C, O)
            if atom_name not in ['N', 'CA', 'C', 'O']:
                continue
            
            # Store atoms by residue
            if residue_id not in residue_buffer:
                residue_buffer[residue_id] = {}
            residue_buffer[residue_id][atom_name] = (x, y, z)
    
    # Validate: Each residue must have all 4 backbone atoms
    for residue_id in sorted(residue_buffer.keys()):
        atoms = residue_buffer[residue_id]
        if all(name in atoms for name in ['N', 'CA', 'C', 'O']):
            backbone_atoms[residue_id] = atoms
        else:
            # Incomplete backbone (missing atom), skip residue
            print(f"Warning: Residue {residue_id} missing backbone atoms, skipping")
    
    return backbone_atoms
```

**Cost Estimate:**
- File I/O: ~50,000 cycles (user-layer, unbounded)
- Parsing loop: ~80,000 cycles (line parsing, float conversion)
- Validation: ~20,000 cycles
- **Total: ~150,000 cycles (offline, no frame constraint)**

### Step 2: Compute Dihedral Angles (φ/ψ)

**Dihedral Angle Formula:**

```
Dihedral(A, B, C, D) = atan2(
    n1 · (n2 × n3),    // Numerator: scalar triple product
    n1 · n2             // Denominator: dot product (plane normal)
)

Where:
  b1 = B - A           // Vector from A to B
  b2 = C - B           // Vector from B to C
  b3 = D - C           // Vector from C to D
  
  n1 = b1 × b2         // Normal to plane 1 (A-B-C)
  n2 = b2 × b3         // Normal to plane 2 (B-C-D)
  
  Result: angle ∈ [-π, π] radians
```

**Backbone Dihedral Definitions:**

```
Phi (φ) angle:
  Dihedral(C_{i-1}, N_i, Cα_i, C_i)
  
  Atoms:
    - C_{i-1}: C atom of previous residue (C of residue i-1)
    - N_i: N atom of current residue
    - Cα_i: CA atom of current residue
    - C_i: C atom of current residue

Psi (ψ) angle:
  Dihedral(N_i, Cα_i, C_i, N_{i+1})
  
  Atoms:
    - N_i: N atom of current residue
    - Cα_i: CA atom of current residue
    - C_i: C atom of current residue
    - N_{i+1}: N atom of next residue (N of residue i+1)

Omega (ω) angle (NOT computed, assumed trans):
  Dihedral(Cα_i, C_i, N_{i+1}, Cα_{i+1})
  Fixed at 180° (peptide bond is planar and trans in most cases)
```

**Pseudocode:**

```python
import math

def vector_subtract(v1, v2):
    return (v1[0]-v2[0], v1[1]-v2[1], v1[2]-v2[2])

def vector_cross(v1, v2):
    return (
        v1[1]*v2[2] - v1[2]*v2[1],
        v1[2]*v2[0] - v1[0]*v2[2],
        v1[0]*v2[1] - v1[1]*v2[0],
    )

def vector_dot(v1, v2):
    return v1[0]*v2[0] + v1[1]*v2[1] + v1[2]*v2[2]

def dihedral_angle(pos_a, pos_b, pos_c, pos_d):
    """
    Compute dihedral angle A-B-C-D.
    
    Args:
        pos_*: (x, y, z) coordinates
    
    Returns:
        angle: float in [-π, π] radians
    """
    b1 = vector_subtract(pos_b, pos_a)
    b2 = vector_subtract(pos_c, pos_b)
    b3 = vector_subtract(pos_d, pos_c)
    
    n1 = vector_cross(b1, b2)
    n2 = vector_cross(b2, b3)
    
    # Avoid division by zero
    dot_n1_n1 = vector_dot(n1, n1)
    dot_n2_n2 = vector_dot(n2, n2)
    if dot_n1_n1 < 1e-10 or dot_n2_n2 < 1e-10:
        return 0.0  # Degenerate (collinear atoms), return 0
    
    # Compute atan2(n1·(n2×n3), n1·n2)
    n2_cross_n3 = vector_cross(n2, b3)  # n2 × b3
    numerator = vector_dot(n1, n2_cross_n3)
    denominator = vector_dot(n1, n2)
    
    angle = math.atan2(numerator, denominator)
    return angle

def extract_dihedrals(backbone_atoms):
    """
    Compute φ/ψ dihedrals for all residues.
    
    Args:
        backbone_atoms: Dict from step 1
    
    Returns:
        dihedrals: List of (residue_id, phi, psi) tuples
    """
    residue_ids = sorted(backbone_atoms.keys())
    dihedrals = []
    
    for i, res_id in enumerate(residue_ids):
        atoms = backbone_atoms[res_id]
        
        # PHI angle: C_{i-1} - N_i - CA_i - C_i
        if i > 0:
            prev_res_id = residue_ids[i-1]
            prev_atoms = backbone_atoms[prev_res_id]
            phi = dihedral_angle(
                prev_atoms['C'],
                atoms['N'],
                atoms['CA'],
                atoms['C'],
            )
        else:
            phi = 0.0  # No phi for first residue (no predecessor)
        
        # PSI angle: N_i - CA_i - C_i - N_{i+1}
        if i < len(residue_ids) - 1:
            next_res_id = residue_ids[i+1]
            next_atoms = backbone_atoms[next_res_id]
            psi = dihedral_angle(
                atoms['N'],
                atoms['CA'],
                atoms['C'],
                next_atoms['N'],
            )
        else:
            psi = 0.0  # No psi for last residue (no successor)
        
        dihedrals.append((res_id, phi, psi))
    
    return dihedrals
```

**Cost Estimate:**
- Dihedral computation: 90 residues × 2 angles × ~1,000 cycles/dihedral ≈ 180,000 cycles
- But vectorizable (SIMD): 90/8 blocks × 15,000 cycles/block ≈ **170,000 cycles (with SIMD)**
- Scalar fallback: ~180,000 cycles (acceptable for offline)

### Step 3: Normalize Angles to [-π, π]

**Normalization Algorithm (Branchless):**

```python
import math

def normalize_angle(angle):
    """
    Normalize angle to [-π, π] using branchless fmod.
    
    Args:
        angle: float in radians (may be outside [-π, π])
    
    Returns:
        normalized: float in [-π, π]
    """
    # Method 1: Standard fmod (branches on sign)
    # normalized = angle % (2*math.pi)
    # if normalized > math.pi:
    #     normalized -= 2*math.pi
    # elif normalized < -math.pi:
    #     normalized += 2*math.pi
    
    # Method 2: Branchless (avoids branch misprediction)
    TWO_PI = 2.0 * math.pi
    PI = math.pi
    
    # Reduce to [0, 2π] via fmod
    reduced = angle - TWO_PI * math.floor(angle / TWO_PI)
    
    # Map [0, 2π] → [-π, π] (branchless)
    # If x > π, subtract 2π; else keep
    # Branchless: use arithmetic (avoid if-statement)
    normalized = reduced - TWO_PI * (reduced > PI)
    
    return normalized
```

**Cost Estimate:**
- fmod + subtraction: ~100 cycles per angle
- 90 residues × 2 angles × 100 cycles ≈ **18,000 cycles**

## TorsionArray Construction

### Output Structure

**Rust Definition:**

```rust
#[repr(C)]
pub struct TorsionArray {
    // Backbone dihedral angles: 90 residues × (φ, ψ)
    pub angles: [f32; 180],
    
    // Metadata
    pub sequence_length: u8,      // Actual # residues extracted (≤ 90)
    pub source_flags: u8,          // Bits: from_pdb, has_disorder
    pub pdb_id: [u8; 4],          // PDB code (e.g., "1MBN")
    pub timestamp_us: u64,         // Parser execution time
    pub crc32: u32,                // CRC32 checksum
    
    // Padding for 64-byte alignment
    _padding: u16,
}

// Total size: 740 bytes (64-byte aligned)
```

**Mapping Formula:**

```
torsion_array.angles[2*i]     = φ_i  (phi angle for residue i)
torsion_array.angles[2*i + 1] = ψ_i  (psi angle for residue i)

For i ∈ [0, sequence_length)
```

**Python Construction (Example):**

```python
import struct
import time
import zlib

def build_torsion_array(backbone_atoms, pdb_id="    "):
    """
    Build TorsionArray struct from backbone atoms and dihedrals.
    
    Args:
        backbone_atoms: Dict from step 1
        pdb_id: PDB code (4-char string, zero-padded)
    
    Returns:
        torsion_array: TorsionArray struct (bytearray, 740 bytes)
    """
    # Extract dihedrals
    dihedrals = extract_dihedrals(backbone_atoms)
    sequence_length = len(dihedrals)
    
    # Initialize angles array (180 × f32)
    angles = [0.0] * 180
    for i, (res_id, phi, psi) in enumerate(dihedrals):
        angles[2*i] = phi
        angles[2*i + 1] = psi
    
    # Build struct manually (no ctypes overhead)
    # Layout: [angles (720B)] [seq_len (1B)] [flags (1B)] [pdb_id (4B)] [timestamp (8B)] [crc32 (4B)] [padding (2B)]
    
    # Pack angles as f32 (single-precision)
    angles_bytes = b''.join(struct.pack('f', a) for a in angles)
    
    # Compute CRC32 over active angles only
    active_angles_bytes = b''.join(struct.pack('f', a) for a in angles[:2*sequence_length])
    crc32_value = zlib.crc32(active_angles_bytes) & 0xffffffff
    
    # Timestamp
    timestamp_us = int(time.time() * 1e6)
    
    # Flags
    source_flags = 1  # Bit 0: from_pdb = 1
    if sequence_length < 90:
        source_flags |= 2  # Bit 1: has_disorder = 1
    
    # PDB ID (pad to 4 chars)
    pdb_id_bytes = pdb_id.ljust(4)[:4].encode('ascii')
    
    # Pack struct
    torsion_array = (
        angles_bytes +  # 720 bytes
        struct.pack('B', sequence_length) +  # 1 byte
        struct.pack('B', source_flags) +      # 1 byte
        pdb_id_bytes +                        # 4 bytes
        struct.pack('Q', timestamp_us) +      # 8 bytes
        struct.pack('I', crc32_value) +       # 4 bytes
        struct.pack('H', 0)                   # 2 bytes padding
    )
    
    assert len(torsion_array) == 740, f"TorsionArray size mismatch: {len(torsion_array)}"
    
    return torsion_array
```

**Cost Estimate:**
- Array packing: ~20,000 cycles (struct assembly)
- CRC32 computation: ~10,000 cycles
- **Total: ~30,000 cycles**

## Error Handling Strategy

### Non-Fatal Errors (Parser Layer)

| Error | Condition | Action | Flag |
|-------|-----------|--------|------|
| **Missing backbone atom** | Residue lacks N, CA, C, or O | Skip residue, continue | None (not flagged) |
| **Degenerate dihedral** | Collinear atoms (angle undefined) | Use 0.0, log warning | None |
| **Truncated sequence** | PDB has > 90 residues | Hard truncate at 90, set flag | `has_disorder = 1` |
| **No chain A** | PDB missing chain A | Reject file, raise exception | None (fatal) |
| **Malformed ATOM line** | Fixed-width parsing fails | Skip line, continue | None |

### Non-Fatal Errors (Supervisor Layer)

| Error | Condition | Action | Flag |
|-------|-----------|--------|------|
| **sequence_length > 90** | Parser error (should not happen) | Warn, skip L5 injection | DVS_WARN_COORDINATES_OUT_OF_BOUNDS |
| **angle out-of-range** | angle ∉ [-π, π] | Warn, clamp to range | DVS_WARN_COORDINATE_NORMALIZATION_FAIL |
| **CRC32 mismatch** | Checksum doesn't match | Warn (informational), proceed | DVS_WARN_CHECKSUM_MISMATCH |

## Cycle Budget Summary

### Per-Frame Cost Breakdown (Offline, User Layer)

```
Step 1: Read + Filter PDB           ~150,000 cycles
Step 2: Extract Dihedrals (SIMD)    ~170,000 cycles
Step 3: Normalize Angles            ~18,000 cycles
Step 4: Build TorsionArray          ~30,000 cycles
────────────────────────────────────────────────
Total PDB → TorsionArray            ~368,000 cycles

Amortized per TorsionArray:
  If called every N frames: 368,000 / N cycles per frame
  
Examples:
  Every frame:    368,000 cycles/frame  (unacceptable, too slow)
  Every 10 frames: 36,800 cycles/frame  (acceptable, 1% overhead)
  Batch processing: 0 cycles/frame     (pre-computed, ideal)
```

**Supervisor Cost (L5 injection):**
```
Supervisor:
  Validation (bounds, CRC):         ~7,000 cycles
  Z_t mapping:                      ~2,000 cycles
  ────────────────────────────────────────────
  Total per injection:              ~9,000 cycles (negligible)
```

**Result:** Parser is **offline responsibility**, supervisor cost negligible.

### C (MMDB Library)

```c
#include "mmdb2/mmdb_manager.h"
#include "my_parser_lib.h"

int parse_pdb_c(const char *pdb_file, TorsionArray *out_array) {
    // Use MMDB for efficient C parsing
    int rc = 0;
    MMDBManager *mmdb = new MMDBManager();
    
    rc = mmdb->ReadCoorFile(pdb_file);
    if (rc) {
        return -1;  // Parse error
    }
    
    // Extract backbone atoms
    PPCChain chain_a = mmdb->GetChain(0, "A");
    if (!chain_a) {
        return -2;  // Chain not found
    }
    
    // Build TorsionArray
    build_torsion_array_c(chain_a, out_array);
    
    delete mmdb;
    return 0;
}

// Cost: ~2 ms on typical machine (compiled C)
```

## Summary: PDB Parsing Protocol

**Responsibility Partition:**
- **Parser (User Layer):** Read PDB, extract dihedral angles, build TorsionArray
- **Supervisor (Deterministic Core):** Validate bounds, map to Z_t, inject into L5

**Cost Model:**
- Parser cost: ~368,000 cycles (offline, unbounded, user responsibility)
- Supervisor cost: ~9,000 cycles per frame (negligible overhead)
- **Supervisor cycle budget: Untouched**

**Languages Supported:**
- Python (BioPython): ~10 ms

**Error Handling:**
- Non-fatal graceful degradation
